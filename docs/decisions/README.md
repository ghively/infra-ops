# Architecture Decision Records

Design decisions for the infra-ops plugin, in [MADR](https://adr.github.io/madr/)
format, filename `YYYY-MM-DD-<topic>.md`.

> Note: these are **plugin architecture** decisions. Per-change *infrastructure*
> records (the `ADR-NNNN-*.md` form generated by `change-scribe` from merged diffs,
> per the `change-documentation` skill) are a separate artifact and are not filed here.

## Status legend

`Proposed` — awaiting accept/reject · `Accepted` — decided, implement · `Rejected` —
decided against, kept for the rationale · `Superseded` — replaced by a later record.
